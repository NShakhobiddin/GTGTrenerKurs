# Global Trainings — «Professional psixolog trener»

Global Trainings Group o‘quv markazining «Professional psixolog trener» kursi uchun landing sahifa, Telegram bot va Mini App.
Ustoz: Dilshod Mannopov. Bepul tanishtiruv kuni: 12-noyabr, 15:00, Toshkent, Chilonzor.

- `index.html`: butun sahifa (statik, build talab qilinmaydi)
- `media/`: videolar va rasmlar
- `api/`, `lib/`: Vercel serverless bot va arizalarni qabul qilish
- `brand/`: logo (SVG), bot avatari, bot rasmi, ikonkalar
- `docs/BOT_SOZLASH.md`: BotFather va Vercel sozlash bo‘yicha qadamma-qadam yo‘riqnoma
- `CLAUDE.md`: tuzilma, ariza oqimi, faktlar va dizayn qoidalari

Lokal ko‘rish uchun shu papkada `python -m http.server` ishga tushirib, `http://localhost:8000` manzilini oching.
